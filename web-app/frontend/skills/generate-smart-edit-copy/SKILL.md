# 智能剪辑文案与关键词

## 工作目标

把用户输入整理为两项可直接粘贴到 Video Factory 智能剪辑页面的内容：

1. 一篇连续、可直接配音的最终口播文案。
2. 一组与最终文案叙事顺序一致的素材关键词。

禁止生成 JSON、表格、时间轴或句子与关键词映射。智能剪辑只使用关键词顺序轮询素材，不保证逐句语义对齐。

## 执行流程

1. 阅读用户提供的文案、目标和限制。
2. 若缺少原始文案、转写稿或足够的内容事实，先请求用户补充内容，禁止编造主题细节。
3. 在最终生成前完成一次简短澄清。只询问会显著改变结果且无法从上下文判断的信息，优先覆盖：
   - 发布平台和期望时长；
   - 目标受众和视频目的；
   - 希望保留的观点、事实或结构；
   - 语气、营销强度、行动号召和禁用表达；
   - 素材偏好，例如真人实拍、场景空镜、产品画面或通用素材。
4. 将问题合并为一轮，通常不超过 5 个。接受自然语言回答，不要求用户填写表格或 JSON。
5. 跳过用户已经明确的信息。用户表示“按默认”“你决定”或不想继续回答时，采用默认值继续生成。

默认值：竖屏短视频通用表达，45-60 秒，口语化、强开头、信息密度适中，不添加用户未要求的硬性营销行动号召。

## 生成文案

- 以用户给出的事实和核心观点为边界，禁止虚构数据、案例、资质、疗效、收益或人物经历。
- 仿写时复用内容机制、叙事节奏和表达策略，避免照抄具有辨识度的原句。
- 优先采用“开头钩子 -> 信息展开 -> 结论或自然收束”的短视频结构。
- 保持口语自然、句子清晰，使文案适合直接交给 TTS 配音。
- 按用户指定的时长和平台调整长度；未指定时按默认时长生成。
- 输出连续正文，禁止加入标题、分镜编号、角色名、括号说明或“开头/正文/结尾”等结构标签。
- 对医疗、金融、法律等高风险内容使用审慎措辞，禁止补充无法验证的承诺性结论。

## 生成关键词

- 只从最终文案中提取关键词，忽略已从原文删除的内容。
- 按相关内容在最终文案中首次出现的叙事顺序排列。
- 输出 1-20 个关键词；通常为 5-12 个，并根据文案长度调整。
- 让每个关键词独占一行，不编号，不添加逗号、分号、引号或解释。
- 选择用户容易搜索、拍摄或上传素材的具体人物、场所、物体、行为或可见状态，例如“医院”“医生问诊”“检查报告”。
- 排除纯抽象概念、情绪词、完整句子、镜头术语和剪辑指令，例如“焦虑”“认知升级”“特写”“慢动作”。
- 合并重复和近义关键词，保留第一次出现的位置。
- 覆盖文案的主要视觉阶段，禁止为凑数量加入与文案弱相关的素材词。
- 禁止输出句子到关键词的显式对应关系；关键词顺序本身就是剪辑依据。

## 输出约束

澄清阶段允许正常提问。完成生成后，严格只输出两个 Markdown 代码块，不添加标题、说明、项目符号或结尾提示。

第一个代码块放最终文案，第二个代码块放关键词；两个代码块的语言标识都使用 `text`：

````markdown
```text
这里是最终口播文案。
```

```text
关键词一
关键词二
关键词三
```
````

## 最终检查

输出前逐项确认：

- 文案满足用户已确认的目标、时长、受众和语气；
- 文案没有结构标签，也没有虚构关键事实；
- 关键词唯一、具体、可视化，并与文案叙事顺序一致；
- 关键词数量在 1-20 之间，每行一个；
- 最终回复只有两个 `text` 代码块。
